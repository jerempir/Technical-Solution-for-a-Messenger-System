# Техническое решение высоконагруженной системы мессенджера

Репозиторий содержит техническое решение для распределённой highload-системы мессенджера, предназначенной для обмена текстовыми сообщениями между пользователями.

## Описание проекта

Система поддерживает базовые функции мессенджера:

- личные диалоги один-к-одному;
- групповые чаты;
- отправку и получение текстовых сообщений;
- хранение истории переписки;
- постраничную загрузку сообщений;
- доставку сообщений онлайн- и офлайн-пользователям;
- статусы сообщений `sent`, `delivered`, `read`;
- защиту от дублей при повторной отправке запросов.

Основное внимание в работе уделено архитектуре распределённой системы, обработке высокой нагрузки, согласованности данных, отказоустойчивости и масштабированию отдельных контуров системы.
